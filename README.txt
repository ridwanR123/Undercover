CARA MENDAPATKAN APK (target Android 16 / API 36, tanpa install apa pun di komputer)
1. Buat akun & repo baru di github.com (boleh dari HP/browser).
2. Upload SEMUA isi zip ini ke repo, termasuk folder .github.
3. Buka tab Actions dan tunggu "Build APK" hijau (sekitar 5 menit).
4. Buka tab Releases di halaman repo, lalu unduh Undercover.apk.
5. Buka file di HP, izinkan "Install dari sumber ini", selesai.
